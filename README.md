# 📡 אנטנות ישראל – מפת אנטנות סלולריות וכיסוי משוער

אפליקציית web (GitHub Pages) + עטיפה לאנדרואיד (APK), המציגה על גבי מפה
אינטראקטיבית את מיקומי האנטנות הסלולריות בישראל וכיסוי משוער שלהן,
לפי מפעיל ולפי דור רשת (2G/3G/4G/5G).

## תכונות
- שכבות בסיס: מפת רחובות (OSM), תמונת לוויין (Esri), מפה כהה
- Clustering חכם לביצועים גם עם אלפי אנטנות
- סינון לפי דור רשת ולפי מפעיל
- מעגלי כיסוי משוער, **מותאמים לצפיפות** - רדיוס קטן יותר באזורים עם הרבה
  אנטנות סמוכות (עירוני צפוף) וגדול יותר באזורים דלילים (כפרי/פתוח).
  עדיין heuristic בלבד, ראו הבהרה למטה
- חיפוש כתובת/רחוב/עיר (Nominatim/OpenStreetMap, מוגבל לתחומי ישראל)
- "המיקום שלי" (GPS)
- תצוגת אנטנות "בהקמה" בנפרד
- **דיווחי משתמשים על נקודות קליטה חלשה** - לחיצה על המפה במצב "דיווח",
  נשמר מקומית בדפדפן (localStorage)
- **מגמת התקנות היסטורית** - גרף sparkline + מונה "כמה אנטנות נוספו מאז
  תחילת המעקב", מבוסס על snapshot יומי שנשמר אוטומטית ב-`data/history.json`
- **כתובות שמורות + התראות** - שומרים כתובת (למשל הבית), והאפליקציה
  מתריעה (באנר + Push notification דפדפני) כשמתגלה אנטנה חדשה (בעיקר 5G)
  בקרבתה, בכל פעם שנטענת
- **מצב אופליין מלא** - Service Worker שומר את קבצי האפליקציה, הנתונים,
  ואריחי מפה שכבר נצפו, כך שהאזורים שביקרת בהם עובדים גם בלי רשת
- מותאם לנייד (bottom sheet, תפריט צד נשלף) ולדסקטופ
- PWA - ניתן "להתקין" ישירות מהדפדפן בנייד גם בלי APK
- עדכון נתונים אוטומטי יומי מ-data.gov.il דרך GitHub Actions

## מקור הנתונים
המשרד להגנת הסביבה מפרסם ב-**data.gov.il** שני מאגרים רשמיים:
- אנטנות סלולריות פעילות – https://data.gov.il/dataset/antennaactive
- אנטנות סלולריות בהקמה – https://data.gov.il/dataset/antenna_hakama

`scripts/fetch_data.py` שולף אותם דרך ה-CKAN API הרשמי וממיר ל-GeoJSON.
כרגע בתיקיית `data/` נמצאים **קבצי דוגמה** (90 נקודות מפוזרות) כדי
שהאפליקציה תעבוד out-of-the-box. יש להריץ את הסקריפט (או לחכות
להרצה האוטומטית הראשונה של ה-Action) כדי לקבל את הנתונים האמיתיים:

```bash
python3 scripts/fetch_data.py
```

> ⚠️ שמות העמודות במאגרים הממשלתיים משתנים לפעמים בין גרסאות. אם אחרי
> ההרצה תראה בסטטיסטיקה "לא ידוע" בכל השדות – פתח את
> `data/antennas-active.geojson` שנוצר, בדוק את שמות המפתחות ב-`properties`,
> ועדכן בהתאם את `FIELD_MAP` בקובץ `js/data-loader.js`.

### תדירות עדכון מומלצת
המאגר הממשלתי עצמו מתעדכן לרוב לא יותר מפעם בשבועות-חודשים (לא בזמן אמת).
לכן הגדרתי ב-`.github/workflows/update-data.yml` הרצה **אוטומטית פעם ביום**
(03:00 UTC) – זה מספיק בהחלט כדי לתפוס כל עדכון, ולא מעמיס את השרת
הממשלתי. אפשר לשנות את תדירות ה-cron בקובץ אם תרצה (למשל פעם בשבוע).

## פריסה ל-GitHub Pages
1. העלה את כל התוכן של התיקייה הזו לריפו חדש ב-GitHub.
2. ב-Settings → Pages → Source, בחר את הענף (למשל `main`) ותיקיית `/ (root)`.
3. תוך דקה-שתיים האתר יהיה זמין בכתובת
   `https://<username>.github.io/<repo-name>/`
4. ודא שב-Settings → Actions → General מופעלת ההרשאה
   "Read and write permissions" עבור ה-workflow של עדכון הנתונים
   (כדי שהוא יוכל לבצע git push לתיקיית data/).

## בניית APK לאנדרואיד
יש שתי דרכים:

### א. אוטומטית דרך GitHub Actions (הכי פשוט)
1. בטאב **Actions** ברפו, בחר בזרימת העבודה **"בניית APK לאנדרואיד"**.
2. לחץ **Run workflow** (הפעלה ידנית).
3. בסיום, קובץ ה-APK (debug) יהיה זמין להורדה תחת **Artifacts** בהרצה עצמה.
4. אפשר גם ליצור טאג גרסה (`git tag v1.0.0 && git push --tags`) כדי שהבנייה תרוץ אוטומטית.

> זהו APK **debug** (לא חתום לחנות Play). לפרסום בפועל ב-Google Play צריך
> ליצור keystore ולחתום עם `assembleRelease` – זה מעבר לסקופ הבסיסי כאן,
> ואשמח לעזור בזה כשתגיע לשלב הזה.

### ב. מקומית (על המחשב שלך)
דרוש: Node.js, Android Studio + Android SDK, JDK 17.
```bash
npm install
bash scripts/prepare-www.sh
npx cap add android      # פעם ראשונה בלבד
npx cap sync android
cd android
./gradlew assembleDebug
# הקובץ יהיה ב: android/app/build/outputs/apk/debug/app-debug.apk
```
או פשוט `npx cap open android` כדי לפתוח את הפרויקט ב-Android Studio ולבנות משם.

## התאמה אישית
- **רדיוסי כיסוי משוער**: `COVERAGE_RADIUS` בתחילת `js/app.js`.
- **צבעי מפעילים**: `OPERATOR_COLORS` באותו קובץ.
- **צבעי דור רשת**: `GEN_COLORS`.
- **מיפוי שמות עמודות מהמקור הממשלתי**: `FIELD_MAP` ב-`js/data-loader.js`.

## הבהרה חשובה על "כיסוי משוער"
המאגר הממשלתי כולל רק **מיקום** ו**דור רשת** של כל מוקד שידור – לא הספק
שידור, לא גובה תורן, לא כיוון אנטנה (אזימוט) ולא דגם. לכן מעגלי הכיסוי
באפליקציה הם **הערכה גסה בלבד** לפי רדיוס טיפוסי לדור הרשת, ולא תחזית RF
מדויקת. זה מוצג במפורש למשתמש גם בתוך הממשק (בפאנל הצד).

## הערות על הפיצ'רים החדשים
- **דיווחי קליטה חלשה וכתובות שמורות נשמרים רק במכשיר** (localStorage) -
  אין כרגע שרת/בסיס נתונים משותף, כך ששני משתמשים שונים לא רואים דיווחים
  אחד של השני. אם תרצה שיתוף בין משתמשים בעתיד - הדרך הכי מהירה היא
  לחבר Firebase Firestore (חינמי בהיקפים קטנים) ולהחליף את `js/reports.js`
  לקרוא/לכתוב משם במקום מ-localStorage.
- **התראות** נבדקות רק כשהאפליקציה *נטענת מחדש* (אין Push אמיתי מהשרת,
  כי מדובר באתר סטטי ב-GitHub Pages ללא backend). זה עדיין שימושי
  למשתמש שפותח את האפליקציה מדי כמה ימים.
- **גרף המגמה ההיסטורית** יתמלא בנתונים אמיתיים ככל שה-GitHub Action
  היומי ירוץ; כרגע יש 14 ימי דמו לצורך הדגמה בלבד.
- **רדיוס כיסוי לפי צפיפות** מבוסס על ספירת אנטנות סמוכות בלבד (proxy
  לצפיפות עירונית) ולא על נתוני אוכלוסין רשמיים - שיפור עתידי אפשרי הוא
  חיבור ל-CBS (הלשכה המרכזית לסטטיסטיקה) לצפיפות אוכלוסין אמיתית לפי יישוב.
